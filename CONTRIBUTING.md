# Contributing

1. Open or select one narrowly scoped issue.
2. Create a branch from `main`.
3. Read `AGENTS.md` before changing code.
4. Run `bash scripts/check.sh` before and after the change.
5. Preserve the working vertical slice and add a regression check.
6. Open a pull request using the repository template.

A feature is not complete merely because an AI response looks convincing. It must produce correct durable records, expose uncertainty, work on a phone, and pass the repository checks.
